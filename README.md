The funniest final text a dying phone sends at one percent battery, in the phone's own voice: "1%. before i go: i have never once been at 100%. i faked it every morning. also i read all your unsent drafts. you are welcome. bye" The turn is the confession: the battery meter lied every morning, and the phone kept the user's unsent drafts to itself.

## Run it

```sh
node main.ts
```

`main.ts` writes the 131-character final text to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` by default), verifying first that it is 1-200 characters with no dash, and that the file on disk round-trips byte for byte.
